01/Manifesto

Most AI agents fail for reasons that have nothing to do with the model.

They reach for tools they were never granted. They execute code outside the boundary you drew. They behave differently on two runs of the same input and nobody can say why. The intelligence is the easy part — governance is the hard part.

I explore that gap through local MCP gateways, policy generators, semantic caches and agent test harnesses. These are evolving projects with explicit limits — local policy checks do not create an operating-system sandbox, and LLM judgments are not deterministic.

Other work spans C++ streaming algorithms, experimental Rust cryptography, industrial telemetry prototypes, collaborative editors and computer-vision notebooks. The index includes 27 public repositories as of 7 November 2026, including learning exercises and profile repositories. Source links make each project's implementation and maturity available to inspect.

An agent you cannot constrain is not an agent. It is an incident with a token budget.
