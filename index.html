01/Manifesto

Most AI agents fail for reasons that have nothing to do with the model.

They reach for tools they were never granted. They execute code outside the boundary you drew. They behave differently on two runs of the same input and nobody can say why. The intelligence is the easy part — governance is the hard part.

My work lives in that gap. Local MCP gateways that refuse unauthorised tool calls. Sandboxes that run untrusted code with a policy attached. Pipelines that compile months of agent behaviour into enforceable rules. Caches that know a hit has gone stale before they hand it back. Test harnesses that make a non-deterministic system reproducible on demand.

Before that: C++ anomaly engines, Rust cryptography, edge ML on industrial OPC-UA buses, real-time collaborative editors, and a great many notebooks that turned into systems. Twenty-five public repositories — most of them built to find out whether an idea survives contact with production.

An agent you cannot constrain is not an agent. It is an incident with a token budget.
